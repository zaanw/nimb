# Nimb

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Nimb supports personal messaging, groups and channels. A user can find a contact, read or send a message, and return to the same conversation and draft.

## Capabilities and Constraints

Profiles include public names, numbers, badges, media and gifts. The market sells collectible gifts for Nimb currency. The wallet manages addresses and their visibility. The feed, notifications, archives, saved messages, chat folders, appearance preferences and authorized moderation remain part of the product. This redesign preserves the working React client, API contracts and stored data.

## Brand Commitments

Keep Nimb's name and existing content. The user confirmed a fully dark interface and supplied Slasher HTML as reference for chats, account screens and collections. Use the reference to understand product hierarchy and density.

## Accessibility & Inclusion

Keep existing font-size and reduced-motion preferences. Support keyboard and touch for navigation, chat and account actions.
