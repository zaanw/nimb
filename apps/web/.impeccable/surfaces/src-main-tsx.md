# Nimb chat workspace

Mode: Operate.

## Direction contract

**Thesis.** Keep the conversation in place while the person changes destination, inspects files, or opens account tools. The messenger should feel like one workspace.

**Own-world.** Dark ink-blue work areas, a plum navigation field and restrained apricot actions. User avatars and collectible artwork are the main visual detail.

**Story.** Open a conversation from the left or use search. Send and read in the centre. Inspect actual attachments on the right without leaving the thread.

**First viewport.** Small independent chat list at left and full-height conversation stage. Permanent dock along the bottom on desktop. Active chat has an optional file pane at wide widths. On phones, the list and active thread are separate views.

**Form.** Code-led web app. The user chose “Полностью тёмный интерфейс” and asked to “Используй HTML-референсы Slasher”. The reference guided density and content hierarchy. The layout was developed directly from the brief without a concept roll.

**Finish.** Inspect the actual app at phone, tablet and desktop widths. Check navigation, file send, reduced motion, focus and collectible purchase. Preserve the baseline captures and record design decisions in DESIGN.md.
