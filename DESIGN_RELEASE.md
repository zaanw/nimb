# Nimb: переработка интерфейса и коллекционный маркет — 20 ноября 2026

Реализован в исходном коде самостоятельный дизайн Nimb с визуальным ориентиром на Slasher: графитовые поверхности, компактная навигация, широкая переписка и акцент на содержимом коллекции. Чужая разметка, скрипты и аккаунты не переносились.

## Что изменилось

- ПК: постоянная боковая навигация, отдельный список чатов и широкая переписка; выбранная ширина меню сохраняется при переходах. Планшет использует компактную панель. На телефоне пять основных разделов, переписка занимает экран и скрывает нижнюю навигацию.
- Профиль: данные человека слева, коллекция справа на ПК/планшете; последовательная композиция на телефоне. Сохранены баннеры, музыка, ссылки, дополнительные имена, номера, значки и Plus. Вход в админку доступен владельцу.
- Маркет: настоящий каталог с ценами, подтверждение покупки за нимбики, личная коллекция, поиск, ошибки с повтором, состояния загрузки и отсутствия результатов. Каталог имеет 4/3/2 колонки в зависимости от доступного места.
- Подарки: исходные локальные изображения и анимации Telegram, отдельный номер внутри каждой коллекции, случайные фон и узор, назначаемые сервером один раз. Номер на диагональной ленте; подробности показывают реальные сохранённые свойства. Это внутренние активы Nimb, без блокчейна и биржи перепродажи.
- Настройки: список разделов и отдельная область содержимого на ПК; переход с кнопкой возврата на телефоне. Лента, кошелёк, админка и формы авторизации используют общие поверхности и типографику.
- Общие диалоги: удержание фокуса, Escape, возврат фокуса инициатору. Есть ссылка пропуска навигации, видимый keyboard focus, подписи полей и уменьшение движения.
- Исправлена ошибка единого хостинга: запросы статических файлов больше не расходуют лимит API. Даже при достижении API-лимита клиент и отложенно загружаемый маркет остаются доступны; ограничения самого API сохранены.
- Исправлен переключатель включения чата в папку: выбор виден сразу, сохраняется до ответа сервера и возвращается к исходному при ошибке.

## Сохранение данных

Новая миграция `20261120190000_collectible_market` добавляет GiftEdition, GiftCounter, GiftPurchase и связь подарка с экземпляром. Старые аккаунты, хеши паролей, сообщения и API существующих функций сохранены. Старые подарки получают номера по порядку ID внутри своего типа, с сохранением ID, владельцев, дат, закреплений и событий. Выданные номера и свойства сохраняются при откатах статов и не разыгрываются заново.

Покупка атомарно проверяет цену на сервере, сохраняет точку восстановления, списывает баланс и выдаёт подарок. UUID запроса предотвращает повторное списание после потери ответа. Проверены параллельные покупки, нехватка баланса, повтор UUID другим пользователем, удаление/возврат подарка через откат. Прежняя бесплатная отправка подарка другу и административная выдача сохранены.

## Установка

В Bonto для приложения Nimb: **Settings → Git remote → Pull from Remote**, ветка **nimb-ethiodeploy**, затем **Restart**. Start script: `start`. Команда применяет миграции Prisma и запускает готовые `bonto-release/api` и `bonto-release/web`; сборка TypeScript на малом контейнере не нужна. Кеш оболочки PWA обновлён до v7. Самостоятельный перезапуск Bonto через эту сессию недоступен; публикация на живом домене после Pull/Restart требует отдельной проверки.

## Оставшиеся ограничения

- `npm run lint` не запускается: в репозитории нет lint script/конфигурации. Проверка типов входит в успешную сборку; форматирование проверено отдельно. Линтер не объявляется пройденным.
- Vite предупреждает о начальном JS-чанке около 666 КБ (196 КБ gzip). Маркет (~8.4 КБ) и Lottie (~170 КБ) загружаются отдельно; дальнейшее разделение основных разделов остаётся улучшением производительности.
- Физический iPhone/Safari, браузерная доставка push через внешний провайдер и живой Bonto-домен в этой сессии не проверены. Проверялись реальные API подписки, сервис-воркер и сценарии интерфейса с разрешениями; это не доказательство доставки push на устройство.
