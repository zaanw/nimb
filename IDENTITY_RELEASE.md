Обновление nimb: оформление, коллекционные адреса и значки

На Bonto: Settings → Git remote → Pull from Remote (ветка nimb-ethiodeploy), затем Restart. Стартовый скрипт — start. Готовые web/API файлы находятся в bonto-release: сборка на хостинге не требуется. При старте Prisma автоматически применит миграцию 20261116140000_identity_plus. Она добавляет поля и журнал выдачи, сохраняя аккаунты и коллекции.

Владелец ID 1: Админ-панель → выберите пользователя → «Значки и Plus». Bug Hunter, Nimb team, Beta tester, верификацию и Plus может выдавать и отзывать только ID 1. Другие администраторы не получают этих прав. Каждая выдача сохраняется в истории.

Настройки → nimb Plus: пять шрифтов имени, эффекты «Золотой перелив» / «Северное сияние», пять оттенков обложки. Владелец также получает радужное имя; миграция включает его для ID 1. После отзыва Plus персонализация обычного пользователя сбрасывается. Системное уменьшение движения и настройка приложения отключают анимацию.

Кошелёк: имена из 3–24 латинских символов (первая — буква, затем буквы, цифры, _), числовые @имена из 1–6 цифр и номера + из 3–12 цифр. Коллекционный номер — адрес внутри nimb, без телефонной связи и SMS. Покупка номера сохраняет @имя; выбранный номер виден в профиле и доступен в поиске. При покупке другого @имени обычное прежнее имя освобождается, купленное остаётся в коллекции. Цена видна до подтверждения. Купленные неактивные имена защищены от регистрации другими пользователями.

Пароли аккаунтов хранятся только как Argon2-хеши в User.passwordHash; исходные пароли прочитать нельзя. Сохранённый пароль можно посмотреть в менеджере паролей браузера для nimb.bonto.page. Восстановление с подтверждённым email доступно на экране входа. Если email не подключён, владелец хостинга может в личном терминале Bonto запустить `npm run recover:owner`: он получит одноразовую ссылку на смену пароля только для ID 1, действующую 15 минут. После смены прежние сеансы завершаются. Ссылку нельзя публиковать.

Секреты инфраструктуры (база, S3, почта) задаются в Bonto → Settings → Environment variables. Локально они находятся в игнорируемом Git файле .env. Эти значения не являются паролем входа в nimb и не входят в готовую web-сборку.

Белая векторная галочка нарисована для nimb по визуальному образцу значка верификации Telegram: https://telegram.org/verify . Она обозначает подтверждение владельцем nimb. Готовый значок Telegram не копируется и не загружается с внешнего сайта при открытии приложения.

Исправление загрузки изображений профиля: новые аватары и баннеры сохраняются в таблице ProfileImage PostgreSQL после преобразования в WebP. Настройка S3 для них не требуется; старые ключи S3 продолжают читаться, пока владелец не заменит изображение. Миграция 20261116190000_profile_image_storage применяется при Restart, не изменяя прежние изображения. Музыка и файлы переписок по-прежнему используют S3. Проверьте свободное место в базе при большом количестве профилей.
