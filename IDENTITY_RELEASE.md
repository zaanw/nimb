Обновление nimb: оформление, коллекционные адреса и значки

На Bonto: Settings → Git remote → Pull from Remote (ветка nimb-ethiodeploy), затем Restart. Стартовый скрипт — start. Готовые web/API файлы находятся в bonto-release: сборка на хостинге не требуется. При старте Prisma автоматически применит миграцию 20261116140000_identity_plus. Она добавляет поля и журнал выдачи, сохраняя аккаунты и коллекции.

Владелец ID 1: Админ-панель → выберите пользователя → «Значки и Plus». Bug Hunter, Nimb team, Beta tester, верификацию и Plus может выдавать и отзывать только ID 1. Другие администраторы не получают этих прав. Каждая выдача сохраняется в истории.

Настройки → nimb Plus: пять шрифтов имени, эффекты «Золотой перелив» / «Северное сияние», пять оттенков обложки. Владелец также получает радужное имя; миграция включает его для ID 1. После отзыва Plus персонализация обычного пользователя сбрасывается. Системное уменьшение движения и настройка приложения отключают анимацию.

Кошелёк: имена из 3–24 латинских символов (первая — буква, затем буквы, цифры, _), числовые @имена из 1–6 цифр и номера + из 3–12 цифр. Коллекционный номер — адрес внутри nimb, без телефонной связи и SMS. Покупка номера сохраняет @имя; выбранный номер виден в профиле и доступен в поиске. При покупке другого @имени обычное прежнее имя освобождается, купленное остаётся в коллекции. Цена видна до подтверждения. Купленные неактивные имена защищены от регистрации другими пользователями.

Пароли аккаунтов хранятся только как Argon2-хеши в User.passwordHash; исходные пароли прочитать нельзя. Сохранённый пароль можно посмотреть в менеджере паролей браузера для nimb.bonto.page. Восстановление с подтверждённым email доступно на экране входа. Если email не подключён, владелец хостинга может в личном терминале Bonto запустить `npm run recover:owner`: он получит одноразовую ссылку на смену пароля только для ID 1, действующую 15 минут. После смены прежние сеансы завершаются. Ссылку нельзя публиковать.

Секреты инфраструктуры (база, S3, почта) задаются в Bonto → Settings → Environment variables. Локально они находятся в игнорируемом Git файле .env. Эти значения не являются паролем входа в nimb и не входят в готовую web-сборку.

Белая векторная галочка нарисована для nimb по визуальному образцу значка верификации Telegram: https://telegram.org/verify . Она обозначает подтверждение владельцем nimb. Готовый значок Telegram не копируется и не загружается с внешнего сайта при открытии приложения.

Исправление загрузки изображений профиля: новые аватары и баннеры сохраняются в таблице ProfileImage PostgreSQL после преобразования в WebP. Настройка S3 для них не требуется; старые ключи S3 продолжают читаться, пока владелец не заменит изображение. Миграция 20261116190000_profile_image_storage применяется при Restart, не изменяя прежние изображения. Музыка и файлы переписок по-прежнему используют S3. Проверьте свободное место в базе при большом количестве профилей.

Обновление оформления и переписок: сохранена тёмная сине-серая основа с тёплым акцентом. Убраны световые дуги, декоративные градиенты, большие рекламные подписи и лишняя высота пустых карточек. Обычные цвета интерфейса не отключают выбранные пользователем эффекты имени.

Новые функции: меню «…» в шапке чата позволяет лично закрепить переписку или убрать её в архив. Фильтры над списком показывают все обычные чаты, непрочитанные или архив. Архив сохраняется до ручного возврата, в том числе при новых сообщениях. Настройки видны только текущему пользователю и обновляются на его подключённых устройствах.

Меню сообщения → «В избранное» сохраняет ссылку на исходное сообщение; раздел доступен из списка чатов и боковой навигации. Есть поиск, постраничная загрузка, открытие переписки и удаление из избранного. Удаление исходного сообщения удаляет и закладку. При выходе из группы её сообщения перестают отображаться в избранном. Избранное хранится на сервере только для своего владельца. «Копировать текст» использует буфер обмена браузера.

Черновики сохраняются на устройстве отдельно для каждого аккаунта и каждой переписки. После обновления страницы текст восстанавливается; отправка в одном чате не очищает черновик другого. При загрузке восстанавливается до 100 черновиков.

Миграция 20261116200000_chat_organization добавляет личные флаги переписки и таблицу закладок, не меняя прежние сообщения. Для установки: Pull from Remote → Restart.

Несколько адресов в профиле: основной @юзернейм, строка «также» с дополнительными именами и отдельные строки коллекционных номеров. Номера отображаются с пробелами (например, +888 0404 0888), а в буфер обмена копируются без пробелов. Нажатие на любой адрес копирует его; длинный список имён можно развернуть.

В кошельке у каждого неактивного купленного адреса есть флажок «Показывать в профиле». Дополнительные адреса по умолчанию скрыты. Основной юзернейм и активный номер отображаются автоматически. Публичные дополнительные имена находятся через поиск пользователей; скрытие адреса сохраняет владение им. Миграция 20261116201500_public_addresses добавляет флаг публичности с безопасным значением false для прежних коллекций.

Откат статов (только ID 1): Админ-панель → карточка пользователя → «Откат статов». Можно сохранить именованную точку, сравнить её с текущими данными и подтвердить восстановление. Снимок включает баланс, подарки, значки, верификацию, Plus, активный юзернейм и номер, коллекционные адреса/их публичность, оформление имени и счётчики активности. Переписки, посты, комментарии, связи подписок, пароль и медиа профиля не удаляются. Счётчики в этом окне — отдельные значения статистики; обнуление не меняет содержимое и реальные связи подписок.

Точки создаются автоматически перед новыми административными начислениями/наградами, покупками и выбором адреса, сохранением оформления. Данные до установки обновления, для которых не существовало точки, восстановить задним числом нельзя. Перед каждым откатом автоматически сохраняется текущее состояние: выбрать эту точку означает отменить откат. Все применения и обнуления записываются в историю операций. Если данные изменились после предпросмотра или прежний адрес уже занял другой пользователь, операция отклоняется целиком.

Миграция 20261116210000_stat_checkpoints добавляет контрольные точки, неизменяемый журнал применений и смещения счётчиков без изменения текущих статов. Установка: Pull from Remote → Restart.

«Обнулить все статы» сначала создаёт целевую точку с нулевым балансом и счётчиками, без подарков, значков и коллекционных адресов, с отключёнными Plus/верификацией и обычным оформлением. Данные пользователя на этом шаге не меняются: нужно просмотреть таблицу и отдельно подтвердить применение. Если основной юзернейм куплен, ему на замену создаётся временный nimb_ID_…; обычный регистрационный юзернейм сохраняется. Сам аккаунт, переписки, публикации, пароль, профиль и фактические связи подписок сохраняются. Обнуление тоже можно отменить через автоматически созданную резервную точку.

Web Push: миграция 20261116220000_persistent_web_push добавляет серверную таблицу WebPushConfig. При отсутствии VAPID-переменных приложение создаёт единственную пару ключей под блокировкой базы; она сохраняется при перезапуске и используется всеми экземплярами. Полная корректная пара из окружения имеет приоритет. Приватный ключ не передаётся в API, браузер или Git. Включение на устройстве: Настройки → Уведомления → Push-уведомления → разрешить браузеру. На iPhone/iPad нужна iOS 16.4+ и запуск PWA с главного экрана.

Уведомление содержит только «Новое сообщение» и открывает соответствующую доступную аккаунту переписку. Для активного видимого чата сервер не отправляет push в этот сеанс; после закрытия/потери фокуса push продолжаются. Просроченные подписки удаляются по 404/410, выход завершает подписку, разрешённая подписка восстанавливается после повторного входа. Кнопка «Проверить уведомление» отправляет тест только на текущий сеанс (до трёх раз в минуту). Успех теста означает принятие службой Web Push; показ баннера зависит от разрешений и настроек ОС.

Бан по IP и браузеру (только ID 1): Админ-панель → пользователь → «Бан по IP и браузеру». Показываются до 30 недавних подключений и история блокировок. Можно выбрать публичный IPv4/IPv6 либо браузер, указать причину, срок 1 час / 24 часа / 7 дней / без срока и отдельно подтвердить. Бан применяется к запросам API, регистрации и входу, завершает подходящие сеансы и активные соединения; на других экземплярах проверка соединения повторяется каждые 30 секунд. Истёкшие баны перестают действовать автоматически. После снятия требуется войти заново; отдельное ограничение аккаунта снимается отдельно.

Бан браузера использует случайный серверный идентификатор в HttpOnly-cookie nimb_device на год; в базе и админке хранится SHA-256-хеш. Это не аппаратный HWID: очистка cookie/данных сайта, приватное окно или другой браузер позволяют его обойти. Canvas-, аудио- и шрифтовый fingerprinting не используется. Внутренние и локальные IP блокировать нельзя; защищены администраторы и их активные подключения. Владелец с корректным паролем может восстановить доступ даже с заблокированного IP. Восстановление пароля не отключено сетевым баном.

По умолчанию заголовку X-Forwarded-For не доверяем. Для Bonto/reverse proxy: если сервер видит внутренний адрес, владелец может в том же окне явно разрешить текущий внутренний прокси; доверие хранится в базе для точного IP и может быть отозвано. Заголовки других источников игнорируются; цепочка разбирается справа до первого недоверенного узла. Внешние доверенные прокси задаются точными адресами в TRUST_PROXY_IPS. После смены IP прокси на хостинге новый адрес нужно разрешить отдельно. Если хостинг не передаёт X-Forwarded-For, реальный IP определить невозможно: используйте бан браузера или настройте прокси. Известные IP/браузеры появляются после следующего входа или API-запроса пользователя с обновлённой версией.

Миграция 20261117090000_network_bans добавляет метаданные сеансов, историю подключений, баны и точные доверенные прокси. Прежние аккаунты и переписки сохраняются. Установка: Pull from Remote → Restart.

Отзыв адресов и списание нимбиков (только ID 1): Админ-панель → пользователь → «Списать нимбики» или «Забрать юзернейм или номер». Списание требует положительной целой суммы, текущего баланса, причины и отдельного подтверждения; можно выбрать весь баланс. Отрицательный баланс запрещён. Если баланс изменился с момента просмотра, действие отклоняется до обновления данных. Один идентификатор запроса применяется один раз даже при параллельной отправке или повторе после обрыва связи.

Отозвать можно основной регистрационный логин, выданный/купленный юзернейм и коллекционный номер. Адрес удаляется из коллекции и публичного профиля, освобождается для других; нимбики за покупку автоматически не возвращаются и владельцу не переводятся. Если адрес был основным логином, вместо него создаётся уникальный технический nimb_ID_…; он показывается в результате и истории, им можно войти с прежним паролем. Вход по email и действующие сеансы сохраняются. Активный отозванный номер отключается.

Перед каждым успешным действием сохраняется контрольная точка. Результат, причина, владелец действия и баланс до/после записываются в AssetReclaim и общую историю админки. Через «Откат статов» можно вернуть состояние до операции; если освобождённый адрес уже занял другой пользователь, восстановление отклоняется целиком. На других устройствах кошелёк и профиль обновляются через существующие события. Миграция 20261117150000_asset_reclaims добавляет журнал без изменения прежних активов. Установка: Pull from Remote → Restart.

Оформление от 20 ноября 2026: интерфейс переработан по предоставленным референсам Slasher. Графитовые поверхности, рамка приложения и верхняя панель на компьютере, раздельные округлые панели списка и переписки, нейтральные входящие/исходящие сообщения. Высота чата учитывает верхнюю панель, прокрутка новых сообщений ограничена контейнером переписки. Основная навигация сбрасывает прокрутку рабочей области. На телефоне сохраняется нижняя навигация, которая скрывается внутри открытой переписки.

В профиле аватарка и описание отделены от публичных имён/номеров на широком экране; на телефоне используется одна колонка. Настройки получили постоянное боковое меню на компьютере и переход «список → раздел → назад» на телефоне. Поиск настроек и существующие обработчики разделов сохранены. Подарки получили оригинальные SVG-иллюстрации Nimb и карточку с реальными данными экземпляра, владельца, отправителя и даты. Это внутренние подарки приложения; блокчейн, NFT-торговля и платный рынок подарков не добавлялись.

Rubik и Inter раздаются с собственного сервера, лицензии SIL OFL находятся рядом с файлами шрифтов. Для устройств без сохранённого выбора стандартный шрифт — Rubik; явный прежний выбор Inter сохраняется. Внешние ссылки Google Fonts удалены, цвет интерфейса PWA изменён на графит, версия кеша оболочки обновлена. Чужие HTML, скрипты, пользовательские данные и иллюстрации из референсов в релиз не входят. База данных и API не меняются; для установки достаточно Pull from Remote → Restart.
